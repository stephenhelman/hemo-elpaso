# TeX Gyre Bonum Bold

Brand typeface for the HOEP wordmark (website name next to the icon). **Not used for body text.**

- File: `texgyrebonum-bold.otf`, Version 2.004, from the TeX Gyre distribution (GUST e-foundry, B. Jackowski and J. M. Nowacki), <https://www.gust.org.pl/projects/e-foundry/tex-gyre/bonum>.
- License: GUST Font License (free, commercial use OK); the text is in `GUST-FONT-LICENSE.txt` next to this file, and the font file's own copyright notice is embedded in the font. It is self-hosted via `next/font/local` (`src/lib/fonts.ts`), unmodified, so the "rename derived works" request does not apply.
- The logo files in `public/brand/` have outlined lettering and need no font.
